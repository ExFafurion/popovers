## Описание

Виджет всплывающей подсказки (popover) на чистом JavaScript. По клику на кнопку появляется окно с заголовком и текстом, центрированное по горизонтали относительно кнопки. Повторный клик скрывает окно.

## Установка и запуск

```bash
npm install
npm run start   # dev-сервер
npm run build   # сборка в dist
npm test        # запуск тестов
